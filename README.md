# vcc : Virtualisation et Cloud Computing

Projet de Master BD2C (FSAC) : une suite de TP dont chacun s'appuie sur le précédent,
jusqu'au workflow complet : inventaire, profils, templates Jinja2, génération cloud-init, déploiement sur KVM.

| Dossier | Contenu |
|---|---|
| tp1-kvm/ | Installation de KVM, création, clonage et template de VM Ubuntu (scripts 01 à 05) |
| tp2-cloudinit/ | Cloud-init : inventaire, profils, templates, generate.py, deploy.sh |

Chaque dossier a son propre fichier Readme avec les prérequis et les commandes.
Les fichiers volumineux (ISO, images de disque) ne sont pas versionnés.
